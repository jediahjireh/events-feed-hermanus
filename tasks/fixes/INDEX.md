# Fixes Knowledge Base

Solutions to problems solved during development. Each fix captures the problem, root cause, and solution so future sessions can reference them instead of re-solving from scratch.

## How to Use

- **Log a fix:** Run `/project:log-fix` after solving a non-trivial bug
- **Search by error:** Run `/project:log-fix search <error message or keyword>`
- **Browse:** Read this index
